# Mushroom Dataset Analysis

Analiza zbioru grzybów obejmująca przygotowanie danych, różne techniki kodowania cech, redukcję wymiarów oraz modelowanie i odkrywanie zależności. Projekt prezentuje kompletny proces analityczny typowy dla Data Science.

## Zakres projektu
- kodowanie cech: **Label Encoding** i **One‑Hot Encoding**
- redukcja wymiarów: **PCA** i **SVD**
- porównanie jakości reprezentacji danych
- klasyfikacja: **Decision Tree**
- reguły asocjacyjne: **Apriori**

## Technologie
- Python
- Pandas, NumPy
- Scikit‑learn
- Mlxtend
- Matplotlib, Seaborn

## Zawartość repozytorium
- notebook z pełną analizą (`mushroom_analysis.ipynb`)
- folder z danymi (jeśli dostępne)
- opis projektu (`README.md`)

## Uruchamianie
Aby uruchomić projekt, wystarczy otworzyć notebook w środowisku z zainstalowanymi bibliotekami używanymi w analizie.

## Podsumowanie
Projekt pokazuje wpływ metod kodowania na dalszą analizę, efektywność redukcji wymiarów oraz jakość klasyfikacji. Reguły asocjacyjne ujawniają zależności między cechami grzybów, wspierając interpretację wyników i lepsze zrozumienie struktury danych.
